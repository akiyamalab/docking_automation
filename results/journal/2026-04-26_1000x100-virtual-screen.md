## 学びと変更

- **centroid box は hang の主犯**: 30Å の固定 box が空白領域に置かれると unidock2 が無限探索ループに入る → fpocket 推奨
- **array job の競合バグ**: `ls > $OUTDIR/_all.txt` を 20 タスクが同時に書き合うと一部タスクが中途半端なリストでチャンク計算 → 50 件取りこぼし。修正: `_all.${JOB_ID}.${SGE_TASK_ID}.txt` (task-local 化)
- **resume 機構の有用性**: `RESUME_FROM` 環境変数で同じ results ディレクトリに追記。長時間ジョブが timeout/cancel されても続きから再開可能
- **`tsubame pull` の race**: AGE が job を qstat から消すタイミングと job script 末尾の tar 完了が必ずしも一致しない → 直後 pull だと不完全 tarball を取る可能性。再 pull で解消
- **2 段階 prep (DMS + box) の効果**: DMS なし vs ありで 8.6 倍 (50s → 6s/受容体)、fpocket box vs centroid で hang 0 件化
- **scheduler 待ち**: array 20 タスク同時起動は混雑時に待たされる。今回は数分以内に全タスク起動できた
